# 大富助手 · 安装包发布仓库

大富助手（中医经方诊所系统）Windows 安装包的发布仓库。

## 下载

- 最新版本：见本仓库 [Releases](../../releases/latest) 页面
- 官网下载：https://www.dafuzhushou.cn/download.html
- 备用下载：阿里云 OSS、Gitee 镜像（见官网「备用下载」区块）

## 说明

- 每个 Release 附完整安装包 `DaFuZhuShou_TCM_Setup_x.y.z.exe` 与对应 SHA-256
- 校验方式：`certutil -hashfile 安装包文件名.exe SHA256`
- 安装包为免安装引导式安装程序，下载后直接运行
